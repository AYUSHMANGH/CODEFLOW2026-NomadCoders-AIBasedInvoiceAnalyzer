# FinSight AI 💰

### Intelligent AI-Powered Bank Statement & Expense Analyzer

FinSight AI is an AI-powered financial intelligence platform that analyzes bank statements, invoices, and transaction records to automatically extract financial data, categorize expenses, detect unusual spending patterns, and generate smart financial insights.

The system combines OCR, NLP, and custom Machine Learning models to transform raw financial documents into meaningful analytics through an interactive dashboard.

---

## 🚀 Features

* 📄 Upload bank statements, invoices, or receipts (PDF/CSV/Image)
* 🔍 Automatic transaction extraction
* 🧠 AI-powered expense categorization
* 📊 Spending analytics dashboard
* 🔁 Recurring payment detection
* 🚨 Unusual transaction & anomaly alerts
* 💡 Smart financial recommendations
* 📈 Monthly spending trends & visual insights

## 🤖 Custom AI Implementation

Instead of relying on GPT/Gemini wrappers, FinSight AI uses:

* Custom NLP preprocessing
* TF-IDF vectorization
* Machine Learning classification models
* Rule-based anomaly detection
* Transaction categorization pipelines

The custom-trained ML model classifies transaction narrations into categories such as:

* Food
* Shopping
* Travel
* Rent
* Utilities
* Salary
* Subscriptions
* EMI

This satisfies the hackathon requirement for a **custom-trained AI model**.

## 📌 Problem Statement

Analyzing financial documents manually is time-consuming and inefficient. Users often struggle to understand spending habits, recurring payments, and financial patterns hidden inside raw bank statements and invoices.

FinSight AI simplifies financial analysis by automatically organizing and interpreting financial data using AI and Machine Learning.
